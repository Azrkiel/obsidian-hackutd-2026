# Fonts in the app

- `stealth-racing/Fonts/PitPalBubble.ttf`: the Pit Pal Bubble display face from the Pit Pal design
  system (team asset). Converted from `PitPalBubble.woff2`; a PostScript name
  (`PitPalBubble-Regular`) was added so iOS can load it.
- `stealth-racing/Fonts/Barlow-*.ttf`: Barlow 400/500/600/700, Copyright 2017 The Barlow Project
  Authors (https://github.com/jpt/barlow), SIL Open Font License 1.1. Converted from the design
  system's woff2 files.
